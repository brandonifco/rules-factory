## Comparator ([`compare.py`](compare.py))

Adapted from [`../../faa-part-107/blind-mapping/compare.py`](../../faa-part-107/blind-mapping/compare.py).
That one was adapted from the trial's comparator, which aligned this map. Changes:

- **Alignment by page again, not designation**, as in the trial. A link needs difflib blocks of
  4+ tokens covering half the shorter span. The page ranges must also be within one page, where a
  range runs from the cited page to the last page marker inside the evidence. The trial compared
  cited pages only, and so could not link die-faces (p. 277, running to p. 280) to anything
  quoted on pp. 278–280.
- **Derived entries** link when a source of one reaches a source of the other through links, and
  `derivedFrom` is compared edge by edge.
- **Fields added:** `beyondAdapter`, `absentFrom`, `definedElsewhere` and `ambiguity.conflict`
  (presence). `crossReferences` are compared map-wide by cited phrase, with page markers removed.
  A phrase made only of a footnote marker is kept as written.
- Kept from Part 107: edges translated through links, non-partner links compared on scope,
  clarity and ambiguity, and exit 1 unless every flag has a row in
  [`resolutions.json`](resolutions.json). It reads the reference from git at `32c5a69`.

`python3 compare.py` writes [`results.json`](results.json).
`python3 compare.py --table` prints the table below.
`python3 compare.py --against ../corpus-map.json` compares the corrected map without writing.

## Where the reference was right and the blind map was not

These are the substantive R rows, kept so the next mapper sees what a careful fresh reading
still got wrong.

- **Doublets** (rows 31–32). "Play the throw twice over" fixes four moves of the number. The
  "aggregate extent" examples give the total and do not license another split.
- **Order of the two dice** (rows 61–62). Each die "entitles" a move of its own. The "six trois …
  then" example illustrates that and states no order.
- **Calling the throw** (rows 21–22) stays out. The move is made "in accordance with" the throw,
  not the call.
- **Full table** (row 40). "Each point occupied by two or more men" does not say whose men. That is
  why the sentence belongs to the entering-man conflict. The blind map's question, whether the
  suspension needs a man up, is answered by the paragraph's subject.
- **What a hit pays** (row 51) remains derived. "The single stake" names the unit the other two
  results multiply.

## Limits: what could not be ruled out

- **The mapper knows backgammon.** A model has read about this game, and probably this book,
  before. The prompt told it to work from the text, and its gaps (turn alternation, the order of
  the dice) read like a mapper doing that. Nothing can prove the text was all it used.
- **Isolation is self-reported.** The session was not observed. The mapper says it read only the
  bundle, but its process started in a rules-factory worktree. The bundle's parent,
  `/tmp/claude-1000`, also holds other sessions' scratch directories, including the coordinator's,
  which contained repository material. Nothing prevented a read. The mapper says it made none.
- **Replacement examples resemble the chapter in shape.** A suspension gate ("a player serving a
  penalty takes no part in play"), a delegated choice from a fixed set ("one month's or two
  months' rent"), and a list of cases that does not cover every input are the method's own
  concepts, and each needs some example. The mapper noticed the first and judged it generic. The
  wording was chosen not to paraphrase the chapter, which is how 0014's run 2 leaked, but the shapes
  remain.
- **The adjudicator had read the reference.** The resolutions were written by the coordinator, one
  context that read both maps and the corpus. It is not the reference's original mapper, but the
  adjudication was not independent either.
- **Shared misreadings stay silent.** Where both maps agree there is no flag.
- **Blind findings no flag carried.** Non-partner blind entries are compared on scope, clarity and
  ambiguity presence only, so some blind questions raised nothing. One is `throw-alternation`: no
  sentence states that players throw in turn, which the chapter only presupposes. It was paired
  with `full-table-suspension`, which is ambiguous too, so no flag appeared. That point has no
  resolution here and is left to the map's next review. It is not part of this record.
- **Evidence rows are the span-coverage proxy.** Each flagged pair was read. Unflagged pairs were
  not re-read.
